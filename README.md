# Conect IA Central

PROTEÇÃO DO CORE — NÃO ALTERAR:

- Não mexer em nada do projeto Zuvvi nem reaproveitar suas configurações.

- Não conectar Supabase, GitHub ou qualquer IA real nesta etapa. Tudo funciona como protótipo/interface, sem dados reais.



ESCOPO DESTA TAREFA:

Crie um NOVO projeto chamado "Conect IA" — uma central de comando para desenvolvimento de software via linguagem natural, para uma pessoa que NÃO é programadora.



Estrutura:

- Sidebar à esquerda com: Início, Projetos, Nova conversa, Histórico, Integrações, Alterações, Configurações (crie TODAS as páginas, incluindo Configurações, sem exceção).

- Tela de conversa central: campo de texto grande, mensagens do usuário e da IA, indicando etapas (entendido / plano / execução / resultado), tudo em português do Brasil.

- Nenhuma funcionalidade falsa: onde depender de conexão futura, mostrar "Disponível após conexão".

- <html lang="pt-BR"> desde o início, título e meta tags já usando o nome "Conect IA" em todo lugar (nunca "Lovable App" genérico).



Ao terminar, liste todas as páginas e componentes criados.
